# Dashboard Analisis Data E-Commerce

## Deskripsi Proyek
Proyek ini bertujuan untuk menganalisis data e-commerce untuk memahami tren penjualan, distribusi revenue, serta perilaku pelanggan. Hasil analisis divisualisasikan dalam bentuk dashboard interaktif menggunakan Streamlit.

## Insight Utama
- Terdapat tren peningkatan jumlah order dan revenue
- Provinsi São Paulo menjadi kontributor terbesar
- Mayoritas pelanggan adalah one-time buyer

## Cara Menjalankan Dashboard
1. Install dependencies:
pip install -r requirements.txt

2. Jalankan:
streamlit run dashboard/dashboard.py
